SPU Pocket v1.2.0 · Android 7+

Le mentor de paraboles, dans votre poche 🌿

Un mentor, pas un maître — il aide à penser ; il ne pense pas à la place.

SPU Pocket embarque un corpus de 65 paraboles réelles et sourcées (Afrique de l'Ouest, Asie, Méditerranée, Nordique, Universelles) consultable sans connexion, et un mode « Poser une question » qui fonctionne dès l'installation, sans serveur.

⬇️ Télécharger l'application (APK) spu-pocket-v1.2.0.apk — 62 Ko — installation directe 📦 Kit complet (zip) APK + AAB + guides + sources — 700 Ko environ 📖 Lire le livre blanc du concept le SPU en détail : pipeline, corpus, éthique, coûts 🧠 Voir le projet complet sur GitHub code source du serveur SPU v4.4

Installation en 4 étapes

  1. Touchez le bouton vert ci-dessus : l'APK se télécharge.
  2. Ouvrez le fichier téléchargé depuis vos notifications.
  3. Android demande l'autorisation « installer des applications inconnues » pour votre navigateur : Autoriser (une seule fois).
  4. Touchez Installer, puis Ouvrir. C'est prêt.

⚠️ Android affiche un avertissement « application inconnue » : c'est normal, l'application est distribuée en direct par son auteur (pas de Play Store). Elle ne demande aucune permission sensible et le mode nomade fonctionne entièrement hors-ligne.
