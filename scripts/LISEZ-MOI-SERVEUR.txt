NOUVEAUTÉS v4.5 (10 novembre 2026)
  • Le narrateur lit TOUTE la réponse : la parabole, son
    interprétation, l'histoire et la mise en perspective —
    dans tous les modes, dès que la voix est activée
    (icône « Voix » dans l'en-tête). Piper sur le serveur,
    repli automatique sur les voix du navigateur.
  • Sources adaptatives : le SPU démarre avec 2 sources et
    synthétise ; si la confiance descend sous 50 %, il ajoute
    une 3ᵉ source, puis une 4ᵉ, puis une 5ᵉ (5 sources libres
    et gratuites). Il garde la première configuration qui
    atteint 50 %, sinon celle qui a le score le plus élevé.
    La trace de l'escalade est visible dans l'onglet réflexion
    (« 2 sources 30 % → 3 sources 40 % → … »).
  • Questions d'affinage plus douces : au plus 2 questions,
    présentées comme des invitations facultatives. L'utilisateur
    peut y répondre, partager librement n'importe quel détail,
    ou cliquer « Poursuivre sans répondre » — la suite du
    dialogue reste complète dans tous les cas.
  • Fin de la section « Le Mentor t'écoute » : la parole du
    Mentor est repliée dans l'onglet réflexion, le corps de la
    réponse n'affiche que les 4 blocs (parabole, interprétation,
    histoire, mise en perspective).
  • Question ouverte finale corrigée : elle s'affiche à nouveau
    à la fin des dialogues Mentor et Deep.

NOUVEAUTÉS v4.4 (rappel)
  • Structure universelle de réponse dans tous les modes.
  • Synthèse des IA repliée dans l'onglet déroulant.
  • Fin des versions figées : service worker en « réseau
    d'abord », la page se rafraîchit à l'arrivée d'une nouvelle
    version. Carte « Quoi de neuf » sur l'accueil.

  IMPORTANT — si l'écran affiche encore « v4.1 » ou « v4.4 » :
  1. Fermez complètement l'onglet puis rouvrez-le (ou
     Ctrl+Shift+R).
  2. Vérifiez que le serveur qui tourne est bien le dernier
     build : curl http://localhost:3000/api/version
     → "serveur": {"version": "4.5" ...}
  3. Vérifiez le corpus : curl http://localhost:3000/api/health
     → "corpus": 65 (si 0 : rejouez le seed, étape 5).

CE QU'EST LE SPU
  L'application web complète (Next.js 16) : les 4 modes
  Oracle, Mentor, Deep et Enfant. Chaque réponse affiche
  TOUJOURS : la parabole, son interprétation, l'histoire, la
  mise en perspective. La synthèse des IA et des moteurs de
  recherche reste rangée dans un onglet déroulant.

CE QU'IL FAUT
  • Linux/macOS avec Bun (ou Node.js 20+), 512 Mo de RAM
  • Ce zip : code source complet, corpus exclu (il se sème)

MISE À JOUR DEPUIS UNE VERSION INSTALLÉE (recommandé)
  1. Dans le dossier du SPU : git pull (dépôt RodAmen001/SPU)
  2. bun install
  3. bun run build
  4. Redémarrez : python3 scripts/demonise.py serveur
  5. curl http://localhost:3000/api/version → "4.5" ✓

INSTALLATION FRAÎCHE EN 6 COMMANDES
  1. Dézippez puis entrez dans le dossier.
  2. bun install
  3. Copiez .env.example vers .env et adaptez :
       DATABASE_URL=file:/CHEMIN/ABSOLU/VERS/ce-dossier/db/custom.db
       ADMIN_TOKEN=une-longue-chaine-aleatoire
     ⚠️ Le chemin de la base doit être ABSOLU.
  4. bunx prisma db push        (crée les 8 tables)
  5. bun run scripts/seed.ts    (sème les 65 paraboles —
       sans cette étape, aucune parabole ne sera proposée !)
  6. bun run build && NODE_ENV=production bun .next/standalone/server.js
     → l'application est sur http://localhost:3000

SURVIE EN DÉMON (production)
  python3 scripts/demonise.py serveur   (démarre, survit au shell)
  python3 scripts/demonise.py gardien   (relance si chute)

VÉRIFIER QUE TOUT EST PRÊT

  → {"status":"ok", "sources":{ "corpus": 65 ... }}
  curl http://localhost:3000/api/version → "4.5"
